# Pac-Man Game

This is one of my first JavaScript projects: a fun, interactive Pac-Man game! Inspired by Chris Courtenay's video tutorial, I’ve added my own unique features and personal touches to make the project my own. 🎮

---

## Inspiration

This project is based on [Chris Courtenay's Pac-Man video tutorial](https://www.youtube.com/watch?v=your-video-link-here). It served as a foundation to learn about JavaScript game development, and I’ve built upon it by adding new features and styles.

---

## Features

### Original Features (from the tutorial)
- **Classic Gameplay:** Move Pac-Man through the maze and eat pellets while avoiding ghosts.
- **Basic Collision Detection:** Pac-Man interacts with walls, ghosts, and pellets.
- **Score Tracking:** A simple score counter updates as you eat pellets.

### My Additions
- **Custom Maze Design:** I created a unique maze layout to enhance the gameplay.
- **Dynamic Ghost Behavior:** Ghosts now have random movement patterns and varying speeds.
- **Power-Up Mode:** Added special pellets that allow Pac-Man to eat ghosts for a limited time.
- **Sound Effects:** Included sound effects for eating pellets, ghosts, and game-over events.
- **Game Over Animation:** A smooth animation sequence when Pac-Man loses all lives.


---

## Technologies Used

### Frontend
- **HTML5 Canvas:** For rendering the game and its elements.
- **CSS3:** Styling and responsive design.
- **JavaScript:** Core game logic, animations, and interactivity.
